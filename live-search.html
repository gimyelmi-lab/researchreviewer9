국문·영문 검색어를 별도로 보내고 DOI 기준으로 중복을 합칩니다. 검색일, 검색어, API 원문 링크를 기록합니다.

2장 문헌고찰을 위한 읽기 구조

검색을 먼저 실행하면 검색 주제에 맞는 검토 순서를 표시합니다.

  1. 핵심 개념과 범위: 검색 결과의 제목·저널·초록으로 연구 분야와 용어를 분류하고, 원문 정의를 확인합니다.
  2. 접근·변환 방법: 선택 논문에서 입력 데이터, 변환 도구, 출력 환경, 정보 손실을 원문 근거 위치와 함께 기록합니다.
  3. 검증과 사례: 시각화·주행환경·물리 시뮬레이션·현장 검증을 구별하고 지표·기준선·실측 자료를 추출합니다.
  4. 연구 공백 후보: 문헌이 다루지 않은 항목을 원문 범위와 검색 범위에 한정해 잠정 정리합니다.
